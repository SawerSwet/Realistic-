# Win81 UltraTune

Набор скриптов для **Windows 8.1**: максимальная оптимизация слабого ноутбука + кастомизация в стиле **Windows 11** (тёмная тема, фиолетовые обои с луной, виджеты CPU/RAM/SSD и часы, классическое меню Пуск), чтобы система перестала быть похожей на Windows 8.

## Быстрый старт

1. Нажми **Code → Download ZIP** и распакуй в любую папку.
2. Запусти `START.bat`. Он сам запросит права администратора.
3. Выбери пункт **1 (FULL SETUP)** и жди. Нужен интернет для скачивания Open-Shell и Rainmeter.
4. Перезагрузи ноутбук.

## Модули

| Модуль | Что делает |
|---|---|
| `00-backup.ps1` | Точка восстановления + экспорт реестра в `%USERPROFILE%\Win81UltraTune\backup` |
| `01-optimize.ps1` | ~20 твиков скорости (см. ниже) |
| `02-customize.ps1` | Тёмная цветовая схема, фиолетовый акцент окон, обои, мелкие значки панели задач, отключение чармов и горячих углов |
| `03-tools.ps1` | Скачивает и ставит Open-Shell (меню Пуск) и Rainmeter (виджеты), включает скины UltraTune |
| `04-wallpaper.ps1` | Генерирует фиолетовые ночные обои с луной и озером (как на твоём фото) без интернета |

## Что оптимизируется

- План питания «Высокая производительность».
- Визуальные эффекты на максимум скорости (сглаживание шрифтов и миниатюры остаются).
- Задержка меню 0 мс, убран искусственный старт-делей приложений.
- Телеметрия, CEIP, DiagTrack и NDU (известная утечка памяти в 8.1) отключены.
- Службы Fax, RemoteRegistry, Media Player sharing, геолокация отключены; Windows Search переведён в ручной режим.
- Удалены метро-приложения: Bing Новости/Финансы/Спорт/Путешествия, почта, пасьянс, Xbox-игры и т.д.
- Очистка temp, кэша Центра обновлений.
- OneDrive скрыт из проводника.

## Как выглядит после

- Тёмные окна и панель задач с фиолетовым акцентом.
- Сгенерированные обои: ночное фиолетовое озеро с луной.
- Часы и виджеты CPU/RAM/SSD в правом верхнем углу (Rainmeter).
- Меню Пуск вместо метро-экрана: при первом запуске Open-Shell выбери стиль **Windows 7**.
- Чармы и горячие углы отключены, загрузка сразу на рабочий стол.

## Как откатить

- Win+R → `rstrui` → точка восстановления «Win81UltraTune backup».
- Reg-файлы старых настроек: `%USERPROFILE%\Win81UltraTune\backup` (двойной клик для возврата).
- Open-Shell и Rainmeter удаляются через «Программы и компоненты».
- Вернуть поиск: `services.msc` → Windows Search → Тип запуска: Автоматически.

## Честные ограничения Windows 8.1

Настоящие скругления окон и «акриловая» прозрачность как в Win11 в 8.1 бесплатными средствами невозможны (это только платный Stardock WindowBlinds). Этот набор даёт максимум бесплатного: тёмная схема, обои, виджеты, меню Пуск, мелкая панель задач. Система будет ощущаться совсем не как Windows 8.
