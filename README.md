# Win81 UltraTune

Набор скриптов для **Windows 8.1**: максимальная оптимизация слабого ноутбука + кастомизация в стиле **Windows 11**, чтобы система перестала быть похожей на Windows 8.

## Быстрый старт

1. **Code → Download ZIP**, распакуй.
2. Запусти `START.bat` (сам запросит права администратора).
3. Выбери **1 (FULL SETUP)**. Нужен интернет.
4. Установщики Aero Glass и Nexus откроются окнами — просто нажимай «Далее».
5. Перезагрузи ноутбук.

## Модули

| Модуль | Что делает |
|---|---|
| `00-backup.ps1` | Точка восстановления + бэкап реестра |
| `01-optimize.ps1` | ~20 твиков скорости |
| `02-customize.ps1` | Тёмная схема, фиолетовый акцент, обои, мелкая панель задач, без чармов |
| `03-tools.ps1` | Open-Shell (меню Пуск) + Rainmeter (виджеты CPU/RAM/SSD и часы) |
| `04-wallpaper.ps1` | Генератор фиолетовых обоев с луной и озером (v2: плавные горы, мерцающее отражение) |
| `05-win11look-plus.ps1` | **Aero Glass** (настоящая прозрачность и размытие окон) + **Winstep Nexus** (панель по центру снизу, как таскбар Win11) |

## Финальная настройка вида (2 минуты, один раз)

После установки Nexus:

1. ПКМ по доту → **Preferences → Position**: край **Bottom**, выравнивание **Center**.
2. ПКМ по панели задач Windows → **Свойства** → включи **Автоматически скрывать панель задач** (док её заменяет).
3. В **Preferences → Themes** выбери тёмную плоскую тему.
4. Open-Shell при первом запуске: стиль **Windows 7**.

Итог: тёмные прозрачные окна с размытием, обои с луной, док по центру, часы и виджеты в углу — Windows 8.1 не узнать.

## Как откатить

- Win+R → `rstrui` → точка «Win81UltraTune backup».
- Reg-файлы: `%USERPROFILE%\Win81UltraTune\backup`.
- Aero Glass, Nexus, Open-Shell, Rainmeter удаляются через «Программы и компоненты».
- Вернуть поиск: `services.msc` → Windows Search → Автоматически.

## Честные примечания

- **Aero Glass** бесплатен, но в свободной версии показывает маленький водяной знак в углу рабочего стола и изредка напоминание о донате. Убрать его можно только донатом разработчику.
- **Nexus** бесплатен для личного использования.
- Все ссылки проверены: Aero Glass 1.4.6 (зеркало Archive.org, оригинальный сайт закрыт), Nexus с официального winstep.net.
